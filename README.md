# Agent Skills Repository

Collection of AI agent skills. Install skills from [skills.sh](https://skills.sh/) using:

```bash
npx skills add <owner/repo>
```

## Installing Skills from This Repository

```bash
# Azure DevOps integration
npx skills add shkreios/agents/skills/azure-devops

# Cursor agent semantic code search
npx skills add shkreios/agents/skills/cursor-agent

# User-friendly error messages
npx skills add shkreios/agents/skills/error-messages

# Production-grade frontend design
npx skills add shkreios/agents/skills/frontend-design

# Chrome browser automation via Playwriter
npx skills add shkreios/agents/skills/playwriter

# Azure DevOps PR label sync from work item tags
npx skills add shkreios/agents/skills/pr-tag-sync

# Skill creation guide
npx skills add shkreios/agents/skills/skill-creator

# Vitest unit testing
npx skills add shkreios/agents/skills/vitest
```
